# Xebia Internship: Tableau Analytics Dashboards

This repository contains my final data visualization submissions for the Xebia Internship program. Both dashboards were built completely from scratch using Tableau Desktop.

## Dashboard 1: Sample Superstore Performance
An end-to-end operational analysis of corporate sales, profits, regional performance, and transactional outliers.
* **Key Findings:** Identified the sales-to-profit relationship and mapped out top and bottom performing states across the regions.

## Dashboard 2: Shark Tank India Investment Analytics
An interactive investor portfolio tracker mapping over 700 startup pitches from the dataset.
* **Key Findings:** Tracks total investments by sharks (Namita, Aman, Peyush, etc.), highest-funded industry sectors, and original vs. final deal valuations.

---
*Note: To view these interactive dashboards, please download the `.twbx` packaged workbook files and open them using Tableau Desktop or Tableau Viewer.*
